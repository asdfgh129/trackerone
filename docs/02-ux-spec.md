# 02 · 体验与界面规范

## 1. 信息架构

```
App
├── 启动 / 会话恢复
├── 引导
│   ├── 选择模式（跟踪本机 / 查看设备 / 两者都要）
│   ├── 服务器档案
│   ├── 登录（查看设备时）
│   ├── 权限向导
│   └── 绑定本机设备
└── 主框架（底部导航，按模式动态）
    ├── 地图
    │   ├── 设备详情卡片
    │   ├── 设备详情页
    │   ├── 历史回放
    │   └── 地图筛选
    ├── 设备
    │   ├── 设备列表
    │   ├── 设备详情
    │   └── 新增/编辑（P1）
    ├── 告警
    │   ├── 事件列表
    │   └── 事件详情
    ├── 跟踪（仅"跟踪本机"或"两者都要"）
    │   ├── 状态面板
    │   ├── 跟踪配置
    │   ├── 预设选择
    │   └── 诊断
    └── 我的
        ├── 服务器与账号
        ├── 地图设置
        ├── 通知设置
        ├── 隐私与权限
        ├── 诊断
        └── 关于
```

### 导航规则

| 模式 | 底部导航 |
|---|---|
| 跟踪本机 | 跟踪 / 诊断 / 我的 |
| 查看设备 | 地图 / 设备 / 告警 / 我的 |
| 两者都要 | 地图 / 设备 / 告警 / 跟踪 / 我的 |

- 地图是"查看设备"模式的默认页；跟踪模式默认页是跟踪面板。
- 推送/深链进入时临时覆盖默认页，返回后回到原 Tab。
- 未登录且未配置服务器时，任何需要服务器的页面都引导到服务器设置。

## 2. 关键流程

### 2.1 首次启动

```
启动
 └─ 有有效配置/Token？ ──是──▶ 主框架
            │否
            ▼
      欢迎页（价值说明）
            ▼
      选择模式
       ├─ 跟踪本机 ──▶ 服务器（上报地址）──▶ 设备标识 ──▶ 权限向导 ──▶ 跟踪面板
       └─ 查看/两者 ──▶ 服务器（API 地址）──▶ 登录 ──▶ 权限（前台定位/通知）
                                              └─▶ 绑定本机（可选）──▶ 主框架
```

### 2.2 开始跟踪

```
跟踪面板 ──▶ 点击开关
              ├─ 权限不足 ──▶ 权限说明页 ──▶ 系统授权 ──▶ 返回重试
              ├─ 后台受限 ──▶ 厂商省电引导页 ──▶ 设置 ──▶ 状态刷新
              └─ 成功 ──▶ 运行中（常驻通知 + 状态卡片）
```

### 2.3 推送直达

```
点击通知
 └─ App 未启动 ──▶ 初始化 ──▶ 已登录？ ──否──▶ 登录 ──▶ 继续
                                      │是
                                      ▼
                              事件详情（地图定位到事件点）
```

## 3. 页面规范

### 3.1 欢迎 / 模式选择

**目标**：30 秒内让用户理解"这个 App 能做什么"，并做出模式选择。

**结构**

- 顶部：品牌插画/地图背景
- 标题：一句话价值（"跟踪这台手机，也查看所有设备"）
- 三张模式卡（图标 + 标题 + 一行说明）
- 底部：主按钮"继续"，次按钮"我有服务器地址"

**状态**

- 无服务器配置：主按钮进入服务器设置。
- 已有配置：直接进入登录或主框架。

### 3.2 服务器档案

**字段布局**

```
服务器名称      [ 我的服务器            ]
服务器地址      [ https://track.example.com ]
                ⓘ 将自动使用 :5055 上报位置
[ 高级 ] 展开
   API 地址    [ 自动 ]
   上报地址    [ 自动 ]
   [ ] 允许自签名证书（不推荐）
[ 测试连接 ]   [ 保存并继续 ]
```

**测试连接结果**

| 结果 | 展示 |
|---|---|
| 成功 | ✅ 服务器名称 + 版本 + 延迟 |
| 401 | ⚠️ 服务器可达，需要登录 |
| TLS 错误 | ❌ 证书不受信任，建议检查域名/证书 |
| 超时 | ❌ 无法连接，检查地址与网络 |
| 非 Traccar | ❌ 未检测到 Traccar API |

### 3.3 登录

- 邮箱/密码 + 登录按钮
- "使用 Token 登录"折叠入口
- "OIDC 登录"（P1，服务器支持时显示）
- 忘记密码：打开服务器 Web 端重置页
- 错误：表单内联提示，不禁用整个页面

### 3.4 权限向导

分三步，每步只申请一个权限，解释"为什么"：

| 步骤 | Android | iOS | 文案要点 |
|---|---|---|---|
| 1 | 通知 | 通知 | 常驻状态与告警 |
| 2 | 前台定位 | 使用期间定位 | 地图定位与首次定位 |
| 3 | 后台定位 + 运动识别 | 始终定位 + 运动 | 锁屏后继续上报；可随时停止 |

- 每步都有"稍后再说"，但开始跟踪前必须完成。
- 永久拒绝时展示"去设置"按钮 + 图文路径。
- Android 额外展示厂商省电白名单引导（小米/华为/OPPO/vivo/三星）。

### 3.5 地图（核心页）

**布局**

```
┌─────────────────────────────────────┐
│ [搜索设备…]        [筛选] [图层]     │  ← 悬浮顶栏
│                                     │
│              ·  ·                   │
│         ·        🚗                 │  ← 地图
│    🚚                 ·             │
│                          📍(本机)   │
│                                     │
│  ┌───────────────────────────────┐  │  ← 设备卡片（可上拉）
│  │ 🚗 京A·12345        2 分钟前  │  │
│  │ 62 km/h · 电量 78% · 在线     │  │
│  │ [历史] [指令] [跟随]          │  │
│  └───────────────────────────────┘  │
│                        [◎ 定位]     │
└─────────────────────────────────────┘
```

**顶栏**

- 搜索：按名称/车牌/IMEI 过滤，结果高亮并居中。
- 筛选：分组、在线状态、是否有告警。
- 图层：标准/卫星/暗色；尾迹开关；聚合开关。

**标记**

| 状态 | 颜色 | 图形 |
|---|---|---|
| 在线静止 | 灰绿 | 圆点 + 设备图标 |
| 在线行驶 | 蓝 | 箭头（按方位旋转） |
| 离线 | 灰 | 空心圆 + 最后时间 |
| 告警 | 红 | 脉冲环 |
| 本机 | 主题色 | 定位图标 + "本机"标签 |

**设备卡片**

- 上拉展开：详情、今日轨迹、指令、分享。
- 左右滑动：切换相邻设备。
- 跟随模式：地图持续居中，用户拖动即退出。

**空/异常状态**

| 状态 | 展示 |
|---|---|
| 无设备 | 插画 + "还没有设备" + 添加/绑定入口 |
| 全部离线 | 顶部横幅"所有设备离线，最后更新 …" |
| 无网络 | 缓存地图 + 顶栏离线标记 |
| 权限缺失 | 地图中心提示 + 授权按钮 |

### 3.6 跟踪面板

```
┌─────────────────────────────────────┐
│  本机跟踪                     [设置] │
│  ┌───────────────────────────────┐  │
│  │  ● 运行中                     │  │
│  │  最后上报 12 秒前 · 队列 0    │  │
│  │  电量 78% · 精度 高 · 间隔 60s│  │
│  │        [ 停止上报 ]           │  │
│  └───────────────────────────────┘  │
│                                     │
│  快捷操作                           │
│  [ 立即定位 ] [ SOS ] [ 省电模式 ]  │
│                                     │
│  今日统计                           │
│  上报 342 次 · 里程 18.6 km         │
│                                     │
│  ⚠ 后台定位可能被系统限制           │
│     去检查 ›                        │
└─────────────────────────────────────┘
```

**状态卡片颜色**

- 运行中：主题色/绿色
- 已停止：中性灰
- 权限受限：橙色 + 行动按钮
- 失败：红色 + 原因

### 3.7 跟踪配置

分组：

1. **预设**（步行/驾车/资产/高频/省电/自定义）
2. **位置**（精度、间隔、距离、角度）
3. **可靠性**（缓冲、停止检测、心跳、唤醒锁、定位提供者）
4. **通知**（常驻通知文案、通知渠道）
5. **高级**（设备 ID、上报地址、日志）

每项修改即时生效，底部显示"已应用"轻提示；高风险项（关闭缓冲）二次确认。

### 3.8 历史回放

```
┌─────────────────────────────────────┐
│ ← 京A·12345        今日 ▾   [导出]  │
│                                     │
│              地图 + 轨迹             │
│                                     │
│  ┌───────────────────────────────┐  │
│  │ ▶  ━━━━━●━━━━━━━━  14:32/18:10│  │
│  │    1x  2x  4x  8x             │  │
│  └───────────────────────────────┘  │
│  [ 路线 ] [ 停留 ] [ 图表 ] [ 事件 ] │
│  速度 62 km/h · 海拔 43m · 电量 76% │
└─────────────────────────────────────┘
```

- 时间轴拖动时地图同步，游标吸附到最近点。
- 停留列表点击定位到停留点。
- 图表与地图双向联动。
- 导出前选择格式与范围。

### 3.9 事件列表

- 顶部分段：全部 / 未读 / 告警 / 围栏 / 设备。
- 列表项：图标、设备、事件类型、地点、时间、未读点。
- 左滑：标记已读；长按：静音该设备（P1）。
- 空状态："暂无事件" + 检查通知设置入口。

### 3.10 诊断

按"结论优先"组织：

| 区块 | 内容 |
|---|---|
| 总体状态 | ✅ 正常 / ⚠️ 有风险 / ❌ 异常 |
| 权限 | 定位、后台定位、通知、运动识别（逐项 + 去设置） |
| 后台限制 | 电池优化、厂商白名单、前台服务状态 |
| 上报 | 最后成功时间、队列数量、失败原因、平均延迟 |
| 网络 | 当前网络、API 可达性、WebSocket 状态 |
| 服务器 | 地址、版本、认证状态 |
| 日志 | 最近 500 条，可搜索/复制/导出 |

**原则**：每个问题都给出"是什么、为什么、怎么修"。

## 4. 状态设计

每个数据页面必须实现以下状态：

| 状态 | 处理 |
|---|---|
| 首次加载 | 骨架屏（不 spinner 白屏） |
| 空数据 | 插画 + 一句解释 + 一个行动 |
| 缓存数据 | 立即展示 + "更新中"细条 |
| 离线 | 顶部横幅 + 最后更新时间 |
| 错误 | 错误卡片 + 重试 + 诊断入口 |
| 无权限 | 说明 + 去设置 |
| 服务端不兼容 | 版本提示 + 最低版本要求 |

## 5. 设计规范

### 5.1 色彩

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `primary` | #0B6BCB | #7FB8FF | 主操作、本机 |
| `success` | #1E8E5A | #5FD39B | 在线、运行中 |
| `warning` | #B26A00 | #FFC46B | 受限、积压 |
| `danger` | #C62828 | #FF8A80 | 告警、失败 |
| `neutral` | #5F6368 | #C4C7C5 | 离线、次要文本 |
| `surface` | #FFFFFF | #121212 | 背景 |
| `surfaceVariant` | #F1F3F4 | #1E1E1E | 卡片 |

- 使用 `ColorScheme.fromSeed` 生成，品牌色可配置。
- 状态色不单独依赖颜色，必须配合图标/文字（色盲友好）。

### 5.2 字体与间距

- 字体：系统默认（Roboto / SF），支持动态字号。
- 字号：Display 28 / Headline 22 / Title 18 / Body 15 / Caption 12。
- 间距：4 的倍数（4/8/12/16/24/32）。
- 圆角：卡片 16，按钮 12，输入 12，底部卡片顶部 24。
- 触控目标 ≥ 44×44。

### 5.3 动效

- 页面切换：200ms ease-out。
- 底部卡片：250ms spring。
- 地图标记移动：插值动画 500ms（可配置）。
- 遵循"减少动态效果"系统设置。

### 5.4 图标

- 使用 Material Symbols / SF Symbols 风格统一。
- 设备类型图标：车、卡车、摩托、行人、资产、手机。
- 状态图标必须与颜色解耦。

## 6. 无障碍与国际化

- 所有图标按钮有语义标签。
- 地图标记可通过列表访问（不只依赖手势）。
- 支持动态字体 200% 不截断关键操作。
- RTL 布局镜像；数字与单位本地化。
- 文案全部走 ARB；禁止硬编码。
- 时间显示：相对时间（"2 分钟前"）+ 绝对时间（长按/详情）。
- 单位：公制/英制切换，速度、距离、海拔一致。

## 7. 关键文案原则

1. **说结果，不说机制**："后台定位被系统限制" → "锁屏后可能停止上报，点此修复"。
2. **可行动**：错误信息必须包含下一步。
3. **不制造焦虑**：SOS/告警文案明确但不夸张。
4. **隐私透明**：首次上报前明确"位置将发送到 <服务器>"。
